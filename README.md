# 日志分析助手（logging-helper）

一个轻量级静态 Web 应用，可上传日志文件并进行基础分析，展示：

- 错误类型频次（Top N）
- 按小时聚合的错误趋势
- 总行数、错误行数、错误率

## 使用方式

1. 进入项目目录并启动本地静态服务（任选其一）：
   - `python -m http.server 8000`
   - 或其他你常用的静态文件服务器
2. 浏览器访问：
   - `http://localhost:8000`
3. 在页面中上传日志文件（`.log`、`.txt` 等）。

## 日志识别规则（默认）

- 仅统计包含 `ERROR` 或 `FATAL`（不区分大小写）的行作为错误行。
- 时间戳优先匹配如下常见格式：
  - `YYYY-MM-DD HH:mm:ss`
  - `YYYY-MM-DDTHH:mm:ss`
- 趋势按“小时”聚合；无法识别时间戳的错误会归入“未识别时间”。

## 文件说明

- `index.html`：页面结构
- `styles.css`：样式
- `app.js`：日志解析与统计逻辑
